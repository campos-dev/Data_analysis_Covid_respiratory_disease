
📂 Repository Deliverables
The following files have been uploaded to this repository to document and showcase this project:

Dashboard_COVID-19 vs. Respiratory Pathologies.pbix (Power BI Source File): * The native, fully functional Power BI file located in the root folder. Download this file to inspect data connections, the Star Schema model, Power Query steps, and custom DAX measures using Power BI Desktop.
documentation/Dashboard_COVID-19 vs. Respiratory Pathologies.pdf (Static Dashboard Preview): * A high-resolution export of the final dashboard layout. This provides an immediate visual review of the report's design, user interface, and locked symmetric chart axes without requiring any software installation.
documentation/clinical data quality report.pdf (Executive Presentation): * A structured presentation deck summarising the project’s progression. It walks through data quality challenges, transformation rules, and key management findings in an executive-ready slide format.
documentation/disease report.docx (Comprehensive Technical Document): * The full written report detailing the extensive clinical and data analysis conducted for every chart pair (A through H), detailing the medical significance behind the trends.
